## 运行与边界

运行 `python3 scripts/build_statistics.py` 应用规范化修订；`--check`检查当前数据。补丁包含修改前后对象及前置hash，遇到上游漂移拒绝覆盖。所有未修改记录保持不变。旧脚本是分阶段生成器，不是全库重建入口；不要直接用build_primary.py覆盖当前全库（它带旧315节点断言并会丢其他阶段）。本批提供独立统计生成入口，不声称已修复全库历史构建链。

当前所有13条统计内容要求均有引用与任务链接，仍不表示学业要求、全部教学提示、过程任务或实际掌握已经充分验证。绘图和报告题使用自评/教师判据，不强行自动判分。

22个节点对象、61个题目对象及6个节点的出边组发生变化（以patch.json为准）；2节点新增，净增26题。修改过的题目不沿用历史盲解证明。两新节点暂放八下数据分析，并明确标注教材位置待核。

数学旧会话留在原localStorage键，可在首页导出；新数据使用新会话键，避免用新题面解释旧答案。英语键不变。此措施只处理本次数据切换；通用迁移与证据模型留待批次C。

批次A审计表是旧基线历史快照，不重写成新覆盖率。当前结果见本目录结构化node/edge/question审核与requirements.json。用户决定原文见statistics/decisions.json。
