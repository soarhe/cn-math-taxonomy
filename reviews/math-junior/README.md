## 如何review

每张卡包含能力边界、具体任务及答案、先修处理和一个需确认的选择。可在聊天回复“接受S01、S03需调整……”，也可填 `decisions.json`，选择 accept / adjust / defer，并写审核者和日期。未经真实教师审核的内容始终保持 `expertReviewed: false`。

先确认粒度、任务和记录格式；随后批次B补齐43节点、全部相关边和题目的审核。统计13条中的某些项目仍标pending，表示来源和映射已检查，但充分覆盖程度尚未作结论。学业要求仅作局部参考，未宣称完整审计。

## 复现与检查

```sh
python3 reviews/math-junior/build_review.py
python3 reviews/math-junior/validate_review.py
```

生成器读取 `statistics/cards.json` 与 `statistics/requirement-findings.json`，生成审计表、Markdown及基线快照，不改正式数据，不覆盖decisions。请在结构化输入或独立decisions记录反馈，不直接批注生成的Markdown后重跑。

`baseline-lock.json`记录固定基线数据指纹。审核包只适用于该基线；正式数据改变后须审阅差异并升级审核版本，不能单靠重新生成锁文件声称原结论仍有效。校验包含引用、状态、选学分句、计数、基线文件指纹及数值反例，不认证教学效度。
