## 如何理解“补齐”

已补的是已知不足的教学和评价任务设计，不是学生表现或专家认证。逐条对照见[coverage.json](coverage.json)，保留原始finding和状态，列明新任务及量规ID。当前状态为`authored-awaiting-review`，不以添加任务条数宣称full覆盖。

|作品与过程记录|本机保存、逐项人工评分、反馈、JSON导出和打印；附件本身不上传|
|教师独立验证、学生试做|未完成，未填造任何观察证据|

综合素养类条目提供跨次观察及迁移任务；即使完成一次，也不能推断全部素养已达成。人工评分中“未观察”“0未满足”“1部分满足”“2独立完成且有证据”分开，评分需附具体证据，不自动更新诊断引擎。记录保存在浏览器本地，可导出备份；没有服务器账户、附件托管或教师身份认证。

## 真实材料

媒体阅读采用人民日报2025年3月1日刊载的2024统计公报，配套国家统计局同版公报交叉核对；表1男性71909万人、女性68919万人。任务明确统计年份和发布日期，按历史材料使用，不作为当前人口数据。博物馆度量衡材料、地理资源所四季科普、非遗网节气材料均在活动页附出处。没有把自编图假称真实媒体材料，也不复制媒体全文。外部来源可能失效，教师需在上课前检查；学生获取来源本身是相应任务的一部分。

体育任务采用学生自主采集的一手测量数据。午餐任务使用公开菜单或标签并注明日期，比较数学方案，不作个体营养建议。水资源项目保留基线和实施后记录，要求说明不同条件对比较的影响。

## 维护和验收

人工内容源为`authoring/primary-completion/tasks.txt`，每行独立编写；`scripts/build_primary_completion.py`确定性生成活动数据和对照报告，`--check`检测漂移。内容不是从旧finding机械改写成“完成”。旧`reviews/math-primary/coverage.json`保留67 partial/10 gap，作为题库证据历史；当前补充状态看本目录。

```sh
python scripts/build_primary_completion.py --check
python scripts/validate_release_candidate.py
```

验收包括原发布回归、逐项关联完整性、来源引用、参考数值独立计算、未观察语义和不传播掌握状态。浏览器检查活动筛选、图谱入口、记录保存与导出。验收结果见[acceptance.json](acceptance.json)。自动检查只能发现结构、计算与实现错误，不能代替教学有效性验证。
