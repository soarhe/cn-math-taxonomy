## 修复了什么

修复不可能的三角形内切圆/周长条件、HL证明对应错误、旋转题两个正确选项、函数反例、指数条件、百分数解释及多视图重复计数误导。明确分式定义域、圆周角所截弧、凸多边形前提、实际模型适用条件和频率的随机波动。

增加作图、尺规、证明、计算器、数据采集、建模和反思任务，附评分要点。题目要求提交真实作品时，模拟数据必须说明；编写了活动任务不等于学生已经经历活动。

将方法类比或替代解法从硬门槛改为软联系。切线长定理依原页星号标选学；辅助线综合模型等列本库补充。默认年级筛查排除选学和补充节点；显式选择选学节点仍可诊断，仅含补充题的节点保持未测，且不再阻挡同会话其他核心目标。

## 建议怎样review

先看以下四组，足以判断本轮处理规则是否符合预期：

1. `cnm_082_q5`：必须读图、实际描点，评分区分坐标顺序和轴要素。诊断URL加`?target=cnm_082&seed=8`可看到此题。

3. `cnm_p159_q1`至`q4`、`cnm_p194_q4`：小学衔接从无关算术转为对应概念诊断，并修复百分数错误。
4. `cnm_218_q6`、`cnm_291_q6`及实践审阅记录：检查真实活动、模拟数据和模型假设的边界。

开放任务仍依赖自评或人工评分；单次通过只提供初步证据。全部内容未经独立教师审核；新增/改写题不继承上游盲解认证。自动核验是表达式或规则检查，不能检验所有题意。此次视觉核对覆盖本批25道带图题，未把其余历史图片宣称为全部重新验收。引擎仍不表达OR先修组，也没有教学效度验证。

## 复现

在仓库根目录运行：

```sh
python3 scripts/validate_release_candidate.py
```

此命令检查当前发布数据与补丁、审阅索引和版本锁，运行Python与诊断引擎测试、SVG检查和答案自动核验。它不重跑上游批量生成器，也不把历史试验报告当成当前题库结果。若需重放某补丁，用对应的`build_rc_*.py`；已应用时保持幂等，未知前像会失败。
