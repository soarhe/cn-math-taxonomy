# 小学数学与英语：编写门槛验收

当前课程侧共438个节点：数学216个，英语原197个加25个课标补充能力节点。数学116个实践任务、348项观察指标；英语103个任务、309项观察指标。全部438个节点均有任务关联，全部219个任务有定制0/1/2评分示例。

本轮新增数学35个节点专项任务，修正商不变、四则关系、植树、分数除整数与比例等弱关联；补齐原75任务缺失的具体错误及部分完成边界。英语新增40个节点任务和25个课标任务，逐项读取原197节点名称、描述与能力要求后补充实际词汇、阅读材料、问答与表达；移除听力冒充阅读、过去周末冒充今昔对比等错配。

## 四项门槛

| 项目 | 数学 | 英语 |
|---|---:|---:|
| 课程节点与首轮审查记录 | 216 | 222 |
| 实践与表达任务 | 116 | 103 |
| 有任务关联的节点 | 216/216 | 222/222 |
| 有定制评分示例的任务 | 116/116 | 103/103 |

门槛按现有节点加本轮确认遗漏的25个英语能力节点定义；不是依据教材页数或任务总数推算国家课标充分覆盖率。每项评分示例有具体错误与部分完成情境；2级列出本任务须提交的证据，不能用空泛“都对”代替。未观察保持未观察。

[逐节点审查与任务证据](completion.json)包含全部438行、每行任务入口及具体材料。数学基础知识/题库审查沿用216项首轮记录；英语本轮审查的是节点含义与任务，未声称重新完整独立解答788道原题。

## 课程侧与历史诊断基线

新增25个节点及6处名称/描述校正位于`data/primary-curriculum-supplement.json`，知识图谱合并展示。`data/topics.json`、原题库和诊断先修边保留历史基线，因此不能只数该文件来推断课程侧总节点。新节点有实际任务、课标页码和观察指标，没有伪造自动诊断题或先修边。它们仅支持人工观察。

数学内容版为`primary-activities-2026-11.1`，英语为`english-primary-2026-11.4`。旧记录按原版本保留在导出中；不复用旧分数，但对同ID任务保留跨版本已看答案提示。新一次作答归档旧内容，不覆盖历史。
