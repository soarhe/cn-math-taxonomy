引擎版本 `evidence-1`，会话/导出格式 v3。适用于共享引擎的数学和英语。内容数据仍为统计批次 B：1505 节点、2178 边、6185 题。本批没有增加课程内容，也没有完成教师审核或教学有效性验证。

## 规则

| 观察 | 界面结果 | 后续处理 |
| --- | --- | --- |
| 单题正确 | 初步通过 | 仅记录本节点；祖先仍未知 |
| 一次未通过且还有题 | 待确认 | 同节点复测，优先基础/同难度，在候选中优先不同题型 |
| 两次未通过（含明确自报不会） | 待巩固，暂定 | 仅追问硬先修；自报来源保留 |
| 正确和未通过并存 | 不稳 | 保留全部题号及冲突证据，不重置旧记录 |
| 仅一次未通过，预算耗尽或题库不足 | 未测/待确认 | 不判待巩固，不生成该点的确定起点；题库不足时仍可探索硬先修 |
| 暂时跳过（defer） | 未测/待确认 | 不作失败证据、不触发回溯，本轮不再追问该点 |

`skip` 为旧 API 名称，语义是“自报不会”，与新增 `defer` 分开。历史字段 `mastered` 为兼容现有统计/样式保留，**在 evidence-1 中仅表示初步直接支持，绝不表示稳定掌握**；`weak` 是暂定待巩固，`unknown` 包含未测、未确认、暂时跳过。所有状态来源均为 direct，不再创建 inferred 状态。

软先修仍可显示在图中，但不触发诊断追问，不参与候选起点的排除或建议路径传播。图中压缩的间接边标为 indirect，不伪装成硬先修。候选起点是规则排序建议，不是经实证验证的学习根因。没有建议路径不表示不需要学习。

## 记录与重放

每次观察保留 `id/qid/result/text`、`gradingMethod`、`recordedAt`、`engineVersion`、`answerExposed`（本题答案是否在自评或重新作答前暴露）、`feedbackShown`（本次结束前是否显示解析）、`priorFeedbackExposed`（同节点前题已显示解析）。未提供的时间/曝光为 null、来源为 unspecified，不编造证据。

自动判题后用户改判记为 self；从参考答案自评也记为 self。即时复测不能当作独立延时测验。改判额外保留 corrections 的前后结果和时间。重放按原 qid 找题，不再重新抽题；题号不存在、归属错误或重复计入均报错。撤销保留剩余观察的原题号。更正前题导致后续分支变化时，后续已发生的观察仍保留，避免丢弃冲突证据。

摘要单列 `unconfirmed` 和 `deferred`，两者包含在 `untested` 中；未测数不能当成已经验证的失败数。现有题库没有系统的子能力标签，因此仅保证不同题号并优先变化题型，**不声称已实现不同子能力覆盖**。真实学生评估、猜测率、题目区分度及延时复测仍待后续工作。
